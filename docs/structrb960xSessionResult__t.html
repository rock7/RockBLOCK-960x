Detailed Description

Result of an SBD session (AT+SBDIX), as reported by the modem in "+SBDIX: <MO status>, <MOMSN>, <MT status>, <MTMSN>, <MT length>, <MT queued>" ("+SBDI:" on the 9604).

Every session also checks the gateway for mobile-terminated (MT) messages, so check mtStatus and mtQueued even after a send.
