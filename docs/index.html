RockBLOCK 960x Library

Introduction

This is the official C library for the RockBLOCK 9602, 9603 and 9604 satellite modems. It enables sending and receiving data via the Iridium network using Short Burst Data (SBD), and supports Linux, macOS, Windows and Arduino platforms.

The main documentation for this project is available in the README.md of this repository. More specific documentation for the C library can be found below.

This library also builds a shared library that powers the rockblock960x Python package.

Features

  • Simple high-level API to configure and use the RockBLOCK 960x via serial
  • Synchronous and asynchronous SBD sessions
  • Portable C99 core with a pluggable serial port layer
  • Arduino and PlatformIO compatible
