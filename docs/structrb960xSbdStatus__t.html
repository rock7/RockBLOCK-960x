Detailed Description

State of the modem's SBD buffers and ring alert, as reported by AT+SBDSX: "+SBDSX: <MO flag>, <MOMSN>, <MT flag>, <MTMSN>, <RA flag>, <msg waiting>". Same on every model. See rb960xGetSbdStatus().
