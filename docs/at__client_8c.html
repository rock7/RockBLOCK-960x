atStatus_t atClientSendCmd ( atClient_t *  client,
const char *  cmd,
char *  resp,

uint32_t  timeoutMs

Send a command and wait for the final result code.

Intermediate information lines (e.g. "+CSQ: 17,99") are copied into resp separated by '
'. Echoed commands, "OK" and error finals are not copied. Registered URCs arriving mid-command are dispatched to their handlers instead of the response buffer.

Parameters
clientInitialised client.
cmdCommand without line terminator, e.g. "AT+CSQ".
respBuffer for information lines, or NULL to discard. Always NUL-terminated on return when non-NULL.
respSizeSize of resp in bytes.
timeoutMsTime to wait for the final result code.

◆ atClientSendCmdAsync()

atStatus_t atClientSendCmdAsync ( atClient_t *  client,
const char *  cmd,
char *  resp,
size_t  respSize,
uint32_t  timeoutMs 
)

Send a command without waiting for the final result code.

Use for long-running commands (e.g. AT+SBDIX) when the caller can't block. Then call atClientPollCmd() regularly until it returns something other than AT_PENDING. Until then the client is busy: other sends return AT_ERR_BUSY and atClientProcess() does nothing, but URCs are still dispatched by atClientPollCmd().

Parameters
clientInitialised client.
cmdCommand without line terminator. Must stay valid until the command finishes (it's used for echo suppression).
respBuffer for information lines, or NULL to discard. Must stay valid until the command finishes.
respSizeSize of resp in bytes.
timeoutMsTime to wait for the final result code, measured from this call.
Returns
AT_OK if the command was sent (the result comes from atClientPollCmd()), AT_ERR_PARAM, AT_ERR_BUSY or AT_ERR_IO. On any error the client is left idle.

◆ atClientSetDebugHandler()

void atClientSetDebugHandler ( atClient_t *  client,
atDebugHandler_t  handler,
void *  userData 
)

Optional debug / trace handler for viewing AT traffic. Pass NULL to disable. When set, the handler is invoked with:

  • AT_DEBUG_TX for every command sent (without the line terminator) and every atClientWriteRaw() payload;
  • AT_DEBUG_RX for every complete received line (echoes, information lines, finals and URCs alike) and every atClientReadRaw() chunk.

Bytes consumed by atClientWaitFor() prompt matching are not traced. The handler runs in the calling context; keep it fast (e.g. printf).
