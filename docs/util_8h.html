Detailed Description

Small internal helpers shared across the library's source files.

Not part of the public API — not installed, not on the Arduino include path. Just a place to put generic static-style helpers instead of duplicating them per translation unit.

Blocking delay in milliseconds (Linux, macOS, POSIX).

Uses nanosleep(). If a signal interrupts the sleep, it carries on sleeping until the full time has passed.

Parameters
[in]msDelay time in milliseconds. Evaluated only once.
Note
With a strict -std=c99 / -std=c11, define _POSIX_C_SOURCE as 200809L or higher before including any headers, or nanosleep() won't be declared.

Copy a string into a fixed-size buffer, always NULL terminating.

Unlike strncpy(), dst is always NULL terminated (as long as dstSize is at least 1), and the rest of the buffer is not filled with zeros. If src is too long for dst, it is cut off at dstSize - 1 characters.

Parameters
[out]dstBuffer to copy into.
[in]srcNULL-terminated string to copy from.
[in]dstSizeSize of dst in bytes, including space for the terminating NULL.
Note
Does nothing if dst or src is NULL, or if dstSize is 0.
dst and src must not overlap.
The caller can't tell if the string was cut off. If that matters, compare strlen(src) with dstSize before calling.
