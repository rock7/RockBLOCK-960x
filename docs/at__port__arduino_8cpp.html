Detailed Description

Arduino / PlatformIO port for the AT client: implements the portable API in at_port.h.

Works with anything derived from Stream: HardwareSerial, SoftwareSerial, USB CDC serial, etc. A Stream can't be opened at a given baud rate, so bring the port up yourself (Serial1.begin(...)) before atPortOpen() or rb960xBegin(); the baud argument is ignored here. The Stream is kept in the handle's sys.ptr.
