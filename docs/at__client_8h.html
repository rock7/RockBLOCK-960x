Detailed Description

Portable Hayes / 3GPP AT command client.

A small, allocation-free AT command client intended for cellular modules (primarily u-blox, but any Hayes-style modem works). All platform I/O is done through user-supplied callbacks in atPort_t, so the core builds unchanged on Linux, Windows, Arduino, PlatformIO and FreeRTOS/STM32.

Usage outline:

  1. Implement (or reuse) an atPort_t for your platform.
  2. Call atClientInit() with a line buffer you own.
  3. Register URC handlers with atClientRegisterUrc().
  4. Send commands with atClientSendCmd() / atClientSendCmdFmt().
  5. When idle, call atClientProcess() regularly so URCs are dispatched.

Find the Nth field in a comma-separated string.

Sets start to the first character of field idx (counting from 0) and end to one past its last character. end points at the next ',', '\r', '\n' or the NUL terminator. The field isn't copied or NUL-terminated. Its length is (end - start).

Example: in "1,SBD,03.00.04", index 2 gives "03.00.04".

Parameters
[in]srcNUL-terminated source string. Must not be NULL.
[in]idxField index, counting from 0. Evaluated only once.
[out]startconst char * set to the start of the field, or NULL if the field doesn't exist.
[out]endconst char * set to one past the end of the field, or NULL if the field doesn't exist.
Note
An empty field (e.g. "1,,3" at index 1) is valid. It gives start == end, not NULL.
Scanning stops at '\r' or '\n', so a trailing "\r\nOK" in an AT response is ignored.

Find the value part of an AT response, after the colon.

Finds the first ':' in src and sets dst to the first character after it that isn't a space or tab. For example, given "+CGSN: 123456789", dst ends up pointing at "123456789".

Parameters
[out]dstCharacter pointer that receives the result. Set to NULL if src has no ':'. Must be a modifiable lvalue.
[in]srcNUL-terminated AT response string. Must not be NULL.
Note
dst points into src. No copy is made, so src must stay valid for as long as dst is used.
Warning
dst is evaluated more than once. Don't pass an expression with side effects.

Send a command and wait for the final result code.

Intermediate information lines (e.g. "+CSQ: 17,99") are copied into resp separated by '

◆ atClientSendCmdAsync()

atStatus_t atClientSendCmdAsync ( atClient_t *  client,
const char *  cmd,
char *  resp,
size_t  respSize,
uint32_t  timeoutMs 
)

Send a command without waiting for the final result code.

Use for long-running commands (e.g. AT+SBDIX) when the caller can't block. Then call atClientPollCmd() regularly until it returns something other than AT_PENDING. Until then the client is busy: other sends return AT_ERR_BUSY and atClientProcess() does nothing, but URCs are still dispatched by atClientPollCmd().

Parameters
clientInitialised client.
cmdCommand without line terminator. Must stay valid until the command finishes (it's used for echo suppression).
respBuffer for information lines, or NULL to discard. Must stay valid until the command finishes.
respSizeSize of resp in bytes.
timeoutMsTime to wait for the final result code, measured from this call.
Returns
AT_OK if the command was sent (the result comes from atClientPollCmd()), AT_ERR_PARAM, AT_ERR_BUSY or AT_ERR_IO. On any error the client is left idle.

◆ atClientSetDebugHandler()

void atClientSetDebugHandler ( atClient_t *  client,
atDebugHandler_t  handler,
void *  userData 
)

Optional debug / trace handler for viewing AT traffic. Pass NULL to disable. When set, the handler is invoked with:

  • AT_DEBUG_TX for every command sent (without the line terminator) and every atClientWriteRaw() payload;
  • AT_DEBUG_RX for every complete received line (echoes, information lines, finals and URCs alike) and every atClientReadRaw() chunk.

Bytes consumed by atClientWaitFor() prompt matching are not traced. The handler runs in the calling context; keep it fast (e.g. printf).
